# Consulta ALELO CAR

Tela web para consultar chamados de complemento (por matrícula) e importar o extrato semanal da Alelo.

Este repositório tem **só código**. Nenhum dado, chave ou código de acesso fica aqui: os dados ficam em uma planilha privada e o acesso é protegido por um código que é informado na tela.
